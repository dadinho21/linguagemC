# 📚 Linguagem C - Conceitos Básicos

Repositório educacional com exercícios práticos de **Linguagem C**, focado no aprendizado de conceitos fundamentais com códigos simples, bem organizados e **totalmente comentados**.

---

## 🎯 Propósito

Este repositório foi criado para **ajudar iniciantes** a entender os conceitos básicos de programação em C através de exercícios práticos e didáticos.

---

## 📁 Arquivos do Projeto

### 1. **Vetores_Completo.c** 
10 exercícios sobre vetores (arrays 1D)
- Criar e mostrar vetor
- Ler valores do usuário
- Encontrar maior/menor valor
- Somar elementos
- Calcular média
- Contar pares
- Inverter ordem

### 2. **Matriz.c**
10 exercícios sobre matrizes (arrays 2D)
- Criar e exibir matriz
- Ler matriz completa
- Somar todos os elementos
- Encontrar maior e menor valor
- Contar números pares
- Diagonal principal
- Multiplicar por valor

### 3. **String.c**
10 exercícios sobre strings (cadeias de caracteres)
- Ler e exibir nomes
- Contar caracteres
- Juntar duas palavras
- Mostrar letra por letra
- Contar vogais
- Converter para maiúsculas/minúsculas
- Comparar strings
- Verificar palíndromo

### 4. **Funcoes.c**
10 exercícios sobre funções (funções reutilizáveis)
- Criar função simples
- Soma, multiplicação, máximo
- Calcular média
- Verificar se é par
- Calcular quadrado e fatorial
- Contar caracteres de string
- Somar elementos de vetor

### 5. **DesafioFinal.c**
Desafio integrando **Vetores + Matrizes + Strings + Funções**
- Ler nomes de 5 alunos (Strings)
- Ler 3 notas para cada aluno (Matriz)
- Calcular média (Função)
- Guardar médias (Vetor)
- Exibir resultados com status (Aprovado/Reprovado)
- Mostrar estatísticas gerais da turma

---

## 🚀 Como Compilar e Executar

### Windows:
```bash
gcc Vetores_Completo.c -o vetores && vetores.exe
gcc Matriz.c -o matriz && matriz.exe
gcc String.c -o string && string.exe
gcc Funcoes.c -o funcoes && funcoes.exe
gcc DesafioFinal.c -o desafio && desafio.exe
```

### Linux/Mac:
```bash
gcc Vetores_Completo.c -o vetores && ./vetores
gcc Matriz.c -o matriz && ./matriz
gcc String.c -o string && ./string
gcc Funcoes.c -o funcoes && ./funcoes
gcc DesafioFinal.c -o desafio && ./desafio
```
